After it downloads

Vifug is not code-signed yet - a certificate costs money the project does not charge anyone for. Your computer will say so the first time, and once you get past it you are never asked again.

On Windows

  1. Open VifugLyrics-Windows-Setup.exe from your Downloads folder.

  2. Windows shows "Windows protected your PC". Click More info, then Run anyway. That message means the file is not signed, not that anything is wrong with it.

  3. Choose where to install, and let it finish. The installer also asks Windows to allow incoming connections, so phones and the stage display can reach Vifug over your Wi-Fi.

  4. Launch Vifug. 325 songs are already in the library.

If phones still cannot connect, the firewall step needed an administrator and was skipped. Vifug can add the rule itself from Settings › Streaming & output - chapter 16 of the guide walks through it.

On macOS

  1. Open VifugLyrics-Mac-Installer.dmg and drag Vifug into your Applications folder.

  2. Do not double-click it the first time. Right-click Vifug in Applications and choose Open, then Open again in the dialog. Double-clicking an unsigned app only offers a Cancel button; right-click → Open is what gives you the option to continue.

  3. If macOS blocked it anyway, open System Settings › Privacy & Security, scroll down, and press Open Anyway next to the message about Vifug.

  4. Every launch after that is an ordinary double-click.

On Linux

  1. Mark the file executable, then run it. Nothing is installed system-wide and no root is needed.

  2. Or, in a file manager: right-click → Properties → Permissions → tick Allow executing file as program, then double-click it.

chmod +x VifugLyrics-Linux.AppImage
./VifugLyrics-Linux.AppImage

If it will not start on a recent distribution, the AppImage needs FUSE 2. Install libfuse2, or run it unpacked with ./VifugLyrics-Linux.AppImage --appimage-extract-and-run.

Check what you downloaded

Every file is built in the open by GitHub Actions from the public source. Compare the SHA-256 of your copy against the release's own digest - if the two match, the file arrived exactly as it was built. 

# Windows (PowerShell)
Get-FileHash .\VifugLyrics-Windows-Setup.exe -Algorithm SHA256

# macOS / Linux
shasum -a 256 VifugLyrics-Mac-Installer.dmg

Or run it in a browser - nothing to install

Vifug also runs as a hosted web app. The projector, stage display, phone remote and OBS source all work the same, and none of them have to be on the church Wi-Fi. Handy for planning during the week, for a rehearsal on a borrowed laptop, or for a quick look before you install anything.
